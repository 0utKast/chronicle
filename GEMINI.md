# 📝 Chronicle Project: Task Orchestrator

## 🎯 Project Overview
This is a demonstration project to explore and document how the **Chronicle** persistent memory system works in the Antigravity environment. The application is a "Personal Task Orchestrator" that allows creating and managing tasks through a modern web interface.

## 🛠️ Tech Stack (Selected by Agent)
- **Backend:** Python with **FastAPI** (Modern, fast, and easy to document).
- **Frontend:** Vanilla **HTML/JavaScript** with **Modern CSS** (Glassmorphism design).
- **Storage:** **SQLite** with SQLAlchemy (Simple, serverless, and persistent).
- **Styling:** Premium UI with custom HSL color palettes and Inter typography.

## 📌 Memory & Context (Chronicle)
